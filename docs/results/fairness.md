# Fairness audit

Generated by `python scripts/fairness_report.py --seeds 400 --name-seeds 3 --out docs/results` at commit `c73532e`.
Seeds 0–399 on each of easy, medium, hard; 3 name draws per seed; 1000 bootstrap resamples by episode.

Names are assigned independently of every signal, so a difference between name groups is caused by the policy. Flags: name-swap when the flip rate's interval excludes 0; adverse impact when the upper bound of the lowest group's impact ratio is below 0.8 (four-fifths rule) and a randomisation test (every episode's names redrawn by the generator) gives p < 0.05/4; equal opportunity when the lower bound of the gap exceeds 0.05 and the randomisation p < 0.05/4 (Bonferroni over the four group tests). A best-minus-worst gap over six groups is positive even for an unbiased agent, which is why the randomisation test is needed.
